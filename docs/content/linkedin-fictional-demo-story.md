# Fictional LinkedIn project story

This is the approved source material for a future Convive LinkedIn post. It is
not a publication instruction and it must never be presented as a real school
case. Recordings and stills must use the deployed fictional demonstration only.

## Spanish post draft

> ¿Qué ocurre después de que alguien decide contar una situación que le
> preocupa en un centro educativo?
>
> En Convive hemos construido una demostración ficticia para explicar ese
> recorrido de forma clara: una persona inicia una comunicación, el equipo del
> centro la revisa, organiza el seguimiento y responde desde el área
> profesional.
>
> La demo no usa datos reales ni envía comunicaciones a ningún centro. Sirve
> para enseñar una idea sencilla: escuchar con cuidado también necesita un
> proceso comprensible para quien cuenta algo y para quien debe acompañarlo.
>
> Puedes recorrerla aquí: https://conviveaula.com/demostracion

Before publishing, replace neither the link nor the fictional-data boundary
with a claim about a real deployment, collaboration or safeguarding outcome.

## Recording and accessibility checklist

- Record at a readable desktop viewport; create a separate vertical crop only
  when every control and caption remains legible.
- Add Spanish captions that reproduce the intended narration. Do not rely on
  colour, mouse movement or silent UI changes to convey the story.
- Use a calm screen recording with no background music by default. If audio is
  added later, it must not obscure narration and needs an equivalent captioned
  version.
- Review every frame before export for passwords, session cookies, reporter
  credentials, access secrets, private URLs, real people, real schools and
  browser notifications.
- Describe images in the post or accompanying alt text with the visible
  fictional journey, not a diagnostic or legal conclusion about a child.
- Keep the final video and source captures outside this repository unless a
  later issue explicitly approves durable, reviewed media assets.

## Suggested capture order

1. Open a private browser window and visit the public home.
2. Record the empty, non-persistent reporting journey without submitting
   visitor content.
3. Use the completed fictional example only for a prepared illustration.
4. Open the professional role selector and continue with the fictional
   professional workspace.
5. Record one communication, one case and one evidence preview already seeded
   for the demonstration.
6. Stop and review the capture before it leaves the local machine.

The sequence deliberately does not include a real email, an externally sent
notification, a live school, or a real child's situation. Those are outside
the fictional demo boundary.
